# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the code and not the person, and do not harass anyone. Maintainers may edit or remove comments, commits, issues and pull requests that do not follow this, and may ban contributors for repeated or serious violations.

To report a problem, contact the maintainer through [GitHub](https://github.com/Adi-gitX). Reports are handled privately.
